# コマ割りツール

画像を、元の画質のまま1枚にまとめるコマ割りツールです。

**▶ 使う: https://amatsumugishion.github.io/koma-tool/**

- 画像をドラッグ＆ドロップするだけでコマに並びます（何枚かまとめてもOK）
- 線の位置・傾き・色・太さを自由に変えられます。斜めのコマも作れます
- 画像はドラッグで移動、ホイールで拡大縮小。Shift＋ドラッグでまっすぐ動かせます
- 完成サイズは元画像が縮まない大きさに自動で決まります
- PNGで保存、またはコピーしてそのまま貼り付け
- Ctrl+Z で元に戻せます

## 画像はどこにも送られません

ツールはすべてブラウザの中で動きます。入れた画像がサーバーなどに送られることはありません。

## オフラインで使う

ツールの上の「⤓ オフライン用に保存」で、HTMLファイル1つとして保存できます。
保存したファイルをダブルクリックすれば、ネットなしでも使えます。

## 対応環境

パソコンのブラウザ（Chrome・Edge がおすすめ。Firefox・Safari でも使えます）。スマホには対応していません。
