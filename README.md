# KomaStudio(コマ割りツール 改変版)

画像を、元の画質のまま1枚にまとめるコマ割りツールに、吹き出し・文字・図形・モザイクなどを足した版です。

**使う: https://john-mori.github.io/KomaStudio/**

## 元のツールについて

このツールは amatsumugishion さんの「コマ割りツール」を土台にしています。

- 元のツール: https://amatsumugishion.github.io/koma-tool/

作者の方から改変・公開の許可をいただいて公開しています。元のツールの機能(ドラッグ&ドロップで並べる・線の位置と傾きを自由に変える・元の画質のまま書き出す・PNG保存/コピー・Ctrl+Z・オフライン用に保存)はそのまま使えます。

## 足した機能

- 吹き出し(楕円・角丸・強調)と、その中の文字
- 文字(横書き/縦書き・色・大きさ)
- 図形(四角・楕円・直線)
- 範囲を選んでモザイク/ぼかし
- スポイトで拾った色の四角で隠す
- 追加素材のレイヤー一覧(選択・表示/非表示・固定・前後・削除)
- 追加素材のドラッグ移動と右下の四角で拡大縮小
- スマホ対応(タッチでドラッグ・二本指で拡大縮小・1列の画面)
- 作業内容をこの端末内だけに自動保存して、次に開いた時に復旧
- Shorts 1080×1920 のサイズボタン

詳しくは [CHANGES_ja.md](CHANGES_ja.md) を見てください。

## 画像はどこにも送られません

ツールはすべてブラウザの中で動きます。入れた画像がサーバーなどに送られることはありません。自動保存もこの端末のブラウザの中だけです。

## オフラインで使う

ツールの上の「オフライン用に保存」で、HTMLファイル1つとして保存できます。保存したファイルを開けば、ネットなしでも使えます。

## 対応環境

パソコンのブラウザ(Chrome・Edge・Firefox・Safari)と、iPhone の Safari。
